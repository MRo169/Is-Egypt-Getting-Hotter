# 🚀 Is Egypt Getting Hotter? - NASA Space Apps Challenge Project

## 📊 Project Overview
This project presents a comprehensive, interactive data analysis dashboard built using **Microsoft Power BI** and powered by **NASA POWER** climate data (2000–2024). It investigates temperature trends across Egypt's 27 governorates, compares local warming rates with global capital cities, evaluates extreme heat events, and provides a predictive temperature outlook for 2035 using Python models.

> **💡 Note for Reviewers (Interactive Experience):** 
> Due to organizational restrictions on Power BI Public Web Publishing, the full interactive dashboard is provided as a native Power BI file (`project Hot.pbix`) in this repository. 
> **To explore all interactive features (dynamic filters, cross-highlighting, custom tooltips, and multi-page navigation), please download the `project Hot.pbix` file and open it using Power BI Desktop.**

---

## ✨ Key Interactive Features & Dashboard Structure
* **Home Page:** High-level summary cards showing Egypt's overall warming rate (+0.37°C per decade), summer warming trends (+0.49°C per decade), and 2035 outlook (23.48°C).
* **Annual & Seasonal Trends:** Detailed charts analyzing mean annual temperatures, historical highs/lows, and contrasting summer vs. winter warming rates.
* **Comparative Analysis:** Benchmarking Egypt's warming anomaly against global capital cities and contrasting daily vs. monthly data sources.
* **Governorate Breakdown:** Regional analysis highlighting which governorates and climate zones (Delta & Canal, Middle & West Coast, South & Desert) are warming the fastest.
* **Extreme Heat Analysis:** Tracking the sharp rise in hot days exceeding 40°C in Cairo (+10.1 days per decade) and across different seasonal quarters.
* **2035 Climate Outlook:** Predictive forecasting models estimating future temperature averages by governorate.
* **Summary & Findings:** Key statistical takeaways, data limits, and data sources.

## 🛠️ Tools & Technologies Used
* **Microsoft Power BI Desktop:** Data modeling, DAX measures, and interactive UI/UX design.
* **Python (Google Colab, Pandas, SciPy, Scikit-learn, PyMannKendall):** Statistical significance testing, data cleaning, and predictive modeling for the 2035 outlook.
* **Data Sources:** NASA POWER data API and Open-Meteo daily data.
